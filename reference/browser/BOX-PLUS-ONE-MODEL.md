# Box + 1 model for the playable S04 exchange

The [saved development reference](https://chatgpt.com/library?file_id=libfile_c362492ac858819195f5d106beeb54e0&account_id=personal) maps [Coach Russ's Box + 1 walkthrough](https://www.youtube.com/watch?v=E0C7GrAllFg) to Shift Happens! This implementation uses that document as its tactical brief. The local app still treats all coverage thresholds and feedback as draft coaching material.

| Reference beat | First playable exchange |
| --- | --- |
| [1:17 low center](https://www.youtube.com/watch?v=E0C7GrAllFg&t=77s) | Blue C supports the puck-side defender low. When the carrier goes behind the goal, C holds the slot rather than following the puck behind the net. |
| [3:03 wings](https://www.youtube.com/watch?v=E0C7GrAllFg&t=183s) | The puck-side blue wing takes the point lane. The far wing tucks into the high slot. Their targets swap after the carrier emerges on the other side. |
| [5:25 behind the net](https://www.youtube.com/watch?v=E0C7GrAllFg&t=325s) | Red begins low on the LD-side circle, carries into the corner, crosses behind the blue goal, and exits on the RD side. Blue RD guards the near post outside the goalie's space; C protects the slot. The controlled LD holds the inside during this beat. |
| [6:15 side switch](https://www.youtube.com/watch?v=E0C7GrAllFg&t=375s) | Red's exit starts the Red C coverage window. Blue RD steps out to contain the lower-side puck carrier from the inside. Blue C tracks Red LW while controlled LD stays near Red C at the net front and may tie up that skater's stick. Blue wings move through separate paths toward their new responsibilities. Red can cycle to the new puck-side point. |
| [7:37 breakout](https://www.youtube.com/watch?v=E0C7GrAllFg&t=457s) | A blue turnover changes teammate targets to outlets and opponents to backchecking. |

The first read accumulates the controlled LD's net-front coverage until RD reaches the post. The second read starts when the carrier emerges on the far side and checks whether LD stays near Red C at the net front, including an active stick tie-up. The teaching highlight follows Red C instead of pointing at the high zone. LD is not expected to close on the puck carrier while RD handles that side. Guided mode gives one teaching pause and a short exit cue; freer mode uses the same simulation without coaching cues. A player's action, rather than the AI rotation, determines each draft read.

This is one authored, left-defending variation. The full five-decision shift, mirrored right-defending geometry, behind-net player collisions, and coach-approved scoring remain outside this playable slice. The development reference's pressure and center-relief examples are movement references here, not new scored rules.
