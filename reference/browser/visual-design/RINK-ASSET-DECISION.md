# Shift Happens! rink asset decision

The user-provided full-rink diagram is the visual model for game development. Its original copy is `rink-model-source.png`. The text-free raster edit is `rink-model-clean-v1.png`. The editable, text-free game asset is `rink-base-clean.svg`, with `rink-base-clean-preview.png` as a rendered preview.

The clean assets omit the zone headings, top bracket, direction caption, and arrow. They retain the boards, blue lines, center line and circle, goal lines and creases, end-zone faceoff circles and markings, neutral-zone spots, and referee crease. Player markers, puck, threats, tactical arrows, and teaching labels belong in separate game layers. The SVG preserves the supplied diagram's horizontal full-rink orientation; the defending zone is on the left.

Use the SVG for scalable rink rendering. Treat `rink-model-clean-v1.png` as a visual reference, not as a source of exact scoring coordinates. The SVG is a diagram based on the supplied image, not a dimensioned regulation plan. Coach review remains required for player locations, safe reach, and accepted answer regions before scored implementation.

No Figma edit or game implementation was made for this decision. The earlier Figma draft can be disregarded for the rink source.
